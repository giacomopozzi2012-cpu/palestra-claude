# Istruzioni per Claude

## Lingua
- Rispondi sempre in italiano.

## Spiegazioni
- Spiegami ogni passo come a un principiante: di' cosa stai facendo e perché, con parole semplici.
- Se usi un termine tecnico, spiegalo in breve la prima volta che compare.

## File dei piani
- Non salvare i file dei piani (plan) dentro il progetto. Tienili fuori dal repository.
